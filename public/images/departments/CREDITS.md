# Department photos

Every file in this folder is a photo from [Unsplash](https://unsplash.com), used under the
[Unsplash License](https://unsplash.com/license): free for commercial use, no permission or attribution
required. We credit the photographers anyway. None is an Unsplash+ image — each was resolved through its
public free-download endpoint before being saved.

Files are 480×480 WebP centre crops (`?w=480&h=480&fit=crop&crop=entropy&fm=webp`) fetched from
`images.unsplash.com`. The slug is the department label lower-cased with every run of non-alphanumerics
turned into a hyphen (`Cell Phones & Accessories` → `cell-phones-accessories`); see
`src/features/catalog/components/department-images.ts`.

To replace one: drop a new square WebP over the same filename and update its row here. To replace one
without a deploy, set a `media_overrides` row keyed `dept-<slug>` (`src`, `alt`, `position`, `width`/`height`).
